# SEO + GEO Launch Checklist

Use this checklist after the new sitemap, robots route, structured data, and guides are deployed.

## Google Search Console

1. Verify `https://www.mylivingpage.com` as a property in Google Search Console.
2. Submit `https://www.mylivingpage.com/sitemap.xml`.
3. Use URL Inspection on:
   - `/`
   - `/examples`
   - `/pricing`
   - `/guides`
   - `/guides/ats-resume-test`
   - `/guides/recruiter-search-keywords`
   - `/guides/living-page-vs-pdf-resume`
4. Request indexing for any guide URLs that are not already known to Google.
5. Monitor coverage, impressions, and clicks for guide pages weekly for the first month.

## Bing Webmaster Tools

1. Verify `https://www.mylivingpage.com` in Bing Webmaster Tools.
2. Submit `https://www.mylivingpage.com/sitemap.xml`.
3. Inspect the same key URLs used in Search Console.
4. Review Bing AI Performance after the property is verified and the feature is available in the account.
5. Track which guide URLs receive citations or grounding impressions inside Bing AI surfaces.

## Launch Validation

1. Confirm `robots.txt` resolves at the site root and references the production sitemap URL.
2. Confirm `sitemap.xml` includes only acquisition routes and guide URLs, not public profile pages.
3. Confirm canonical tags on `/`, `/examples`, `/pricing`, `/guides`, and each guide URL.
4. Validate JSON-LD on the homepage, examples page, guides hub, and guide article pages.
5. Review GA traffic to guide URLs and compare against Search Console impressions after indexing begins.

## Content Follow-Up

1. Watch which guide titles earn impressions first.
2. Expand the best-performing guide into additional cluster pages before broadening into unrelated topics.
3. Defer IndexNow until guide publishing becomes a recurring process rather than a one-time launch.
